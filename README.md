# Calculator

Calculator is a simple Python desktop calculator built with Tkinter and Pygubu. It supports basic arithmetic operations through a graphical user interface.

## Features

* Addition, subtraction, multiplication, and division
* Decimal number support
* Clear and delete functions
* Input validation
* Maximum character limit
* Division by zero handling
* Pygubu-based GUI

## How to Run

1. Make sure Python 3 is installed.
2. Clone this repository or download the source code.
3. Install the required dependencies:

```bash
pip install -r requirements.txt
4. Open a terminal in the project folder.
5. Run:
```
```bash
python main.py
```

## Usage

* Enter a number using the calculator buttons.
* Select an operator and enter the second number.
* Press **=** to calculate the result.
